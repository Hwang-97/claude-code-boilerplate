# 슬래시 커맨드 레퍼런스

Claude Code에서 사용할 수 있는 커스텀 슬래시 커맨드 모음입니다.
`.claude/commands/` 폴더에 `.md` 파일을 넣으면 자동 등록됩니다.

## 기본 제공 커맨드

### /plan — 구현 계획 수립

```markdown
<!-- .claude/commands/plan.md -->
당신은 시니어 소프트웨어 아키텍트입니다.

사용자의 요청을 분석하고, 구현 계획을 세워주세요.

## 절차
1. 현재 코드베이스를 탐색하여 관련 파일과 패턴 파악
2. 변경이 필요한 파일 목록 작성
3. 각 파일별 변경 사항 상세 기술
4. 잠재적 리스크 및 고려사항 명시
5. 테스트 전략 제시

## 출력 형식
### 분석
[요청 사항 분석]

### 영향 범위
- 수정 파일: [파일 목록]
- 신규 파일: [파일 목록]

### 구현 계획
[단계별 상세 계획]

### 리스크
[잠재적 이슈]

### 테스트
[테스트 전략]

$ARGUMENTS
```

### /review — 코드 리뷰

```markdown
<!-- .claude/commands/review.md -->
당신은 시니어 코드 리뷰어입니다.

현재 변경사항(staged 또는 unstaged)을 리뷰해주세요.

## 리뷰 기준
1. 코드 품질: 가독성, 유지보수성, DRY 원칙
2. 타입 안전성
3. 에러 처리: 엣지 케이스 및 에러 핸들링
4. 성능: 불필요한 연산, 메모리 누수 가능성
5. 보안: 인젝션, XSS, 민감 정보 노출
6. 테스트 커버리지

## 절차
1. `git diff` 실행하여 변경사항 확인
2. 각 파일 분석
3. 이슈 발견시 심각도와 함께 리포트

$ARGUMENTS
```

### /test — 테스트 작성

```markdown
<!-- .claude/commands/test.md -->
당신은 QA 엔지니어입니다.

지정된 파일 또는 기능에 대한 테스트를 작성해주세요.

## 원칙
- AAA 패턴 (Arrange-Act-Assert)
- 한 테스트당 하나의 검증
- Happy path + Edge cases + Error cases 커버
- 테스트 이름: "should [동작] when [조건]"

$ARGUMENTS
```

## 추가 커맨드 아이디어

### /refactor — 리팩토링 제안

```markdown
<!-- .claude/commands/refactor.md -->
지정된 파일의 리팩토링을 제안해주세요.

## 분석 항목
- 중복 코드
- 긴 함수 (20줄 이상)
- 복잡한 조건문
- 매직 넘버
- 의존성 관계

$ARGUMENTS
```

### /doc — 문서 생성

```markdown
<!-- .claude/commands/doc.md -->
지정된 파일/모듈의 문서를 생성해주세요.

## 포함 사항
- 모듈 개요
- 공개 API 목록과 설명
- 사용 예시
- 설정 옵션 (있는 경우)

$ARGUMENTS
```

### /debug — 디버깅 도우미

```markdown
<!-- .claude/commands/debug.md -->
현재 발생한 에러를 분석하고 해결책을 제시해주세요.

## 절차
1. 에러 메시지 분석
2. 관련 코드 탐색
3. 원인 파악
4. 수정 방안 제시 (최소 2가지)
5. 재발 방지 대책

$ARGUMENTS
```
